A deterministic program (Node 22, stdlib only) that writes a single-line museum placard for an ordinary office object — the office printer, recast as an ancient oracle — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> Oracle, c. 2016. Beige plastic, toner-stained. Consulted daily by all; its answers arrive in a tongue no living employee reads, and are obeyed without question.

160 characters, one line, no trailing newline — inside the 1–180 character gate.

## Run

```sh
node main.ts
```
